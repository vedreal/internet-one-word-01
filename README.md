## The word

**Scrollhole** — the internet is a rabbit hole you fall into by scrolling:
one more post, one more video, one more thread, and the afternoon is gone.

## How it works

`main.py` writes the single word to `/output/entry.txt`, validating it is
1–30 characters and not only whitespace.
